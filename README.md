## Overview

This repository contains the replication code and data for the paper *Air Pollution and Birth Outcomes: Causal Evidence from India*.  *Most* results, tables, and figures in the paper can be reproduced by running the single self-contained R Markdown file provided (some analysis were done by my co-author on Stata, available upon request). The dataset required to run the analysis is included via a link below (in case the link is broken at some point please feel free to email me).

## Paper Summary

We study how in-utero exposure to particulate matter affects birth weight and standard derived measures used in the medical literature, using nationally representative birth records from India. Our analysis draws on the **4th and 5th waves of the Demographic and Health Survey (DHS)**, which contain extensive information on births including measured birth weight.

To address the endogeneity of pollution exposure, we instrument for in-utero particulate matter concentrations using **wind direction**, which provides quasi-random variation in the pollutant exposure a mother receives over her pregnancy. This identification strategy follows Deryugina et al. (2019) and its subsequent adaptation to the Indian context by Balietti, Datta, and Veljanoska.

We find sizable negative effects of particulate matter exposure on birth outcomes. Critically, our estimated effects are substantially larger than those documented in comparable studies conducted in Western country settings, highlighting the severity of the pollution burden in India.
